# 快速开始

## 装好依赖

从源码构建：

```bash
git clone https://github.com/ouyangjiahong26/optiburn
cd optiburn
cargo build --release
# 二进制：target/release/optiburn
```

- Rust 1.98.1（由 `rust-toolchain.toml` 固定，rustup 会自动装好）。
- `xorriso` 在 `PATH` 上：Linux 的默认刻录引擎、读盘首路径、增长模式回退都用它。Debian/Ubuntu 用 `sudo apt install xorriso`。Windows 上没有可用的构建（MSYS2 的包碰不到光驱，实测见 ADR-0008 补记），刻录与读盘都走原生路径，不需要外部工具（ADR-0017、ADR-0018）。
- 对光驱的写权限：通常加入 `cdrom` 组，或用 root。

:::tip[写权限]

Linux 上用 `sudo usermod -aG cdrom "$USER"` 把自己加进 `cdrom` 组，注销重新登录后生效。
不确定当前用户能不能写，先跑 `optiburn probe` 看看设备状态。

:::

图形前端的依赖与命令行相同：Windows 上刻录、增长、读盘都走原生路径，Linux 上默认刻录与读盘首路径用 `xorriso`，增长模式默认原生，只在回退时需要 `xorriso`。

## 用图形界面安装（可选）

- Windows：下载 `OptiBurn_0.1.9_x64-setup.exe`（或 arm64 版），双击安装。
- 无网的 Windows 机器：改用 x64 安装包的 `-offline` 版本，内嵌 WebView2 运行时（安装器约 210 MB），安装全程不需要联网。缺补丁的 Windows 7 上 WebView2 安装器会报 0x8007007F，先从 [Microsoft Update Catalog](https://www.catalog.update.microsoft.com/Search.aspx?q=KB2533623) 离线装 KB2533623 与 KB3063858 再安装。
- Linux：下载 AppImage（`chmod +x` 后直接运行）或 `.deb` 安装包。

安装包都在 [Releases](https://github.com/ouyangjiahong26/optiburn/releases) 页。

## 第一个镜像

把任意目录做成镜像。以仓库自带的 `docs` 目录为例：

```bash
$ optiburn build-image docs -o docs.iso --profile dvd --volume-id OPTIBURN
镜像: docs.iso
  扇区: 682
  字节: 1396736
  文件系统: ISO 9660, Joliet Level 3, UDF 1.02
```

镜像内嵌构建时刻时间戳，所以字节数跟随目录内容变化。`--profile` 决定写哪些文件系统
（`cd` 无 UDF，`dvd` 是默认值，`bd` 写 UDF 2.50），细节见[介质与文件系统](./compatibility)。

不给 `-o` 时，镜像写到当前目录，文件名是 `<源目录名>.iso`。

## 刻录

```bash
optiburn burn docs.iso --device /dev/sr0 --speed 8
```

Windows 的设备路径是 `E:`。Linux 默认用 `xorriso`，Windows 只走原生引擎。默认不主动封盘，能否继续追加取决于介质。`--close-disc` 对 CD 与 DVD-R 封盘，DVD+R 与 BD-R 的原生封盘尚未实现。

刻录前置检查会自动处理介质状态：等盘片就绪（20 秒内每 500 ms 重试一次），已封口的盘拒绝写入，可追加盘提示改用 `append`，随机可写介质（DVD-RAM、BD-RE）直接放行。Linux 上盘被系统挂载时写入会被拦下并提示先卸载。

## 追加

盘上已经有内容时，不要把新镜像刻上去。那会遮住旧文件，Windows 只看最后一个区段。改用
`append`，它读出末区段，把源目录合并成新区段：

```bash
optiburn append photos --device /dev/sr0 --volume-id PHOTOS
```

两平台默认走原生增长，旧文件的数据块原地引用，不重读也不重写。Linux 在随机可写介质、
未知 Profile 或指定倍速时自动回退 xorriso 增长模式。追加后的盘在 Windows 上仍能看到
全部文件，资源管理器要弹出光盘再放回才会刷新挂载视图。

## 验证盘的可读性

1. 刻录前先确认镜像本身能被参考实现读出来：

   ```bash
   xorriso -indev docs.iso -ls /
   ```

2. 刻完盘后，用图形前端的“校验盘片”按钮把盘上内容与源逐文件对比（命令行暂无回读入口）。

3. 有条件的话，把盘插到目标机器上（Windows 或老设备），确认文件名与中文名都正常显示。

更完整的验证方法见[介质与文件系统](./compatibility)。
