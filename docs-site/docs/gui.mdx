# 图形界面

OptiBurn 是 Tauri 2 + React 写的图形前端，四个页面对应四个子命令，与命令行共用同一套核心 crate。

## 四个页面

| 页面 | 对应命令 | 用途 |
|---|---|---|
| 设备 | `probe` | 查看本机光驱与盘片状态，展开盘上文件 |
| 制作镜像 | `build-image` | 把目录做成镜像 |
| 刻录 | `burn` | 把镜像写到盘 |
| 追加 | `append` | 把文件写进可追加的盘 |

任务运行时内容区顶部出现进度条与状态行（“正在刻录，已写入 42%”），刻录与追加类任务
可以随时点“停止”。停止后盘片内容不完整，界面会在停止前让你确认。

## 盘上文件浏览与复制

设备页点击设备卡片展开末区段的目录树，显示名称与大小：

- 单击选中一行，按住指针拖动可框选，Ctrl 或 Shift 加选。
- “复制选中文件”把选中内容抽取到本地暂存目录后放进系统剪贴板，在文件管理器里可直接粘贴。
- 复制会先把文件从光盘读出来，需要一点时间，完成前请不要关闭应用。

## 追加页

- 待刻录文件可以用系统文件选择框多选，或在文件管理器复制文件后回到本页按 Ctrl+V 粘贴。
- 文件在盘根平铺写入。
- 卷标自动沿用盘上现有值，读不到时保持默认。

## 回读校验

刻录与追加两页都有“校验盘片”按钮：把盘上最后一区段抽到本地，与源（追加的文件或刻录的
镜像）逐文件对比内容，差异列成中文清单。校验通过时显示“盘上内容与镜像逐项一致”。

## 任务状态与门禁

- 任务进行中界面会锁定提交入口，避免重复提交。
- 盘被系统挂载时写入会被拦下，对话框提示先卸载。
- 刻录过程中切换页面不会丢失任务状态，四个页面常驻挂载。
